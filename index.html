03Instalação3 métodos

Pronto em um minuto.

Instale uma vez. Depois disso o painel se atualiza sozinho.

01

Baixe o MasterColor.zxp.

Windows e macOS, incluindo Apple Silicon.
02

Abra o ZXP Installer ou o Anastasiy's Extension Manager e arraste o arquivo.

03

Reabra o Premiere em Janela → Extensões → Master Color.

A partir daí o painel avisa e instala as versões novas sozinho.
Baixar .ZXP
01

Baixe o MasterColor.zip e extraia.

02

Copie a pasta com.alexascencio.mastercolor para a pasta de extensões:

Windows  %APPDATA%\Adobe\CEP\extensions\
macOS    ~/Library/Application Support/Adobe/CEP/extensions/
03

Rode o comando do Método 03 para liberar o modo desenvolvedor.

Baixar .ZIP
01

Windows — PowerShell

reg add "HKCU\Software\Adobe\CSXS.11" /v PlayerDebugMode /t REG_SZ /d 1 /f
02

macOS — Terminal

defaults write com.adobe.CSXS.11 PlayerDebugMode 1
03

Reinicie o Premiere.

Só é preciso uma vez por máquina.
